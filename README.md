# Finora (Android)

## بیلد
محتوای این پوشه را در ریشه‌ی ریپو بگذار و push کن؛ GitHub Actions خودکار APK می‌سازد (Artifacts → `Finora-debug-apk`).

## وضعیت
- مرحله ۱: ورود/ثبت‌نام/بازیابی رمز، همگام‌سازی، تم، نوار پایین.
- مرحله ۲: صفحه‌ی خانه کامل + ثبت/ویرایش/حذف تراکنش، فیلتر، تقویم شمسی، چرخه‌ی ماه.
- همگام‌سازی زنده با Supabase Realtime (مثل نسخه‌ی وب)، با چک دوره‌ای به‌عنوان پشتیبان.
- اگر برنامه ناگهانی بسته شد، دفعه‌ی بعد متن خطا نمایش داده می‌شود (قابل کپی).

## تنظیم لینک بازیابی رمز (یک بار، در Supabase)
Authentication → URL Configuration → Redirect URLs → `finora://auth-callback`
